# Licence texts

Canonical texts of the tier A licences, which weightkeep attaches to anything it shares from a repo
that declares one of these licences but has no LICENSE file of its own (ADR 0009).

They come from the SPDX License List data (https://github.com/spdx/license-list-data, `text/`),
fetched on 2026-09-24, and are unmodified. The SPDX License List is published by the Linux Foundation
under the Creative Commons Attribution 3.0 licence. Each text remains under its own terms, which
permit verbatim copying.
